# Security Policy

**Weboardies™** is a hosted web application. 

I take the security of the platform very seriously and continually update it to ensure its stability.

If you discover a security vulnerability, I appreciate your help in disclosing it to me in a responsible manner.

Please **do not report security vulnerabilities via public GitHub issues**, as this exposes the platform to further risk.

Instead, please report vulnerabilities by contacting the creator directly:

**GitHub** - You can try reaching out privately to the creator [@mikroskato62](https://github.com/mikroskato62).

**Discord** - Reach out via the [Discord Server](https://discord.gg/k8VNYn4JZf) privately to an admin (e.g., @mikroskato62).

**Email** - Please email the creator privately at [weboardies@gmail.com](mailto:weboardies@gmail.com).

I aim to acknowledge your report within 72 hours and provide regular updates while working to resolve the issue.

Thank you for helping keep **Weboardies™** and its community safe!
