# Contributing To Weboardies™

First off, thank you for considering contributing to Weboardies™! \
**Please note that this repository serves exclusively as a project showcase**. \
The actual source code for Weboardies™ is maintained in a private repository.

## How To Contribute

### Reporting Bugs or Feature Requests
If you encounter any issues or have feature recommendations (with use cases), please share them with me! \
&nbsp;•&nbsp;
Join my [Discord Server](https://discord.gg/k8VNYn4JZf) and post in the relevant channels or send me a direct message. \
&nbsp;•&nbsp;
You can open an [Issue](https://github.com/mikroskato62/weboardies/issues) to report a bug or request a feature. \
&nbsp;•&nbsp;
You can email me directly at [weboardies@gmail.com](mailto:weboardies@gmail.com).

### Improving Documentation
You are welcome to suggest improvements or fixes to the documentation files of this public showcase repository. \
&nbsp;•&nbsp;
You can join my [Discord Server](https://discord.gg/k8VNYn4JZf) and post in the relevant channels. \
&nbsp;•&nbsp;
You can open an [Issue](https://github.com/mikroskato62/weboardies/issues) to discuss the changes. \
&nbsp;•&nbsp;
You can submit a [Pull Request](https://github.com/mikroskato62/weboardies/pulls) with fixes to any of the documentation files.

## Code of Conduct
Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). \
By participating in this project you agree to abide by its terms.
